# BG3d81

Site vitrine de **BG3d81** : impression 3D sur mesure en PETG à Graulhet (Tarn).

- Impression de fichiers (STL, 3MF, STEP)
- Conception CAO sur mesure
- Pièces de remplacement
- Prototypes et boîtiers
- Accessoires pour camping-car vendus sur [eBay](https://www.ebay.fr/usr/bg3d-81)

Site en ligne : https://nanou974.github.io/bg3d81/

## Contenu

- `index.html` : la page du site
- `merci.html` : la page affichée après l'envoi d'une demande de devis
- `img/` : logo, portrait, photos des réalisations et des services

Le formulaire de devis est envoyé par [FormSubmit](https://formsubmit.co), avec compression automatique des fichiers joints en .zip (10 Mo maximum).
